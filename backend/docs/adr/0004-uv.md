# ADR-0004 — uv como gerenciador de dependências

- **Status:** Aceito
- **Data:** 2026-09-29
- **Ticket:** CPBS-275

## Decisão
`uv` para dependências, lockfile (`uv.lock`), venv e execução. Ferramentas: ruff, mypy, pytest, import-linter. Python 3.13 (`.python-version`).

## Alternativas consideradas
- **Poetry / pip-tools:** mais lentos; uv cobre instalação, lock e execução numa ferramenta só.

## Consequências
- Desenvolvedores precisam do `uv` instalado (README).
- CI e Docker usam `uv sync --frozen`.
