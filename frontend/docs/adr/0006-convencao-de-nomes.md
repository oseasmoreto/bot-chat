# ADR-0006 — Convenção de nomes: camelCase

- **Status:** Aceito
- **Data:** 2026-09-29

## Decisão
- camelCase em funções, métodos e variáveis; PascalCase em componentes e tipos; `use` + PascalCase em hooks; UPPER_SNAKE_CASE em constantes de módulo.
- O contrato da API já chega em camelCase (o backend converte), então os tipos gerados seguem o mesmo padrão.
