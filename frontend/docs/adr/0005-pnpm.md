# ADR-0005 — pnpm como gerenciador de pacotes

- **Status:** Aceito
- **Data:** 2026-09-29

## Decisão
`pnpm` (via corepack) com lockfile commitado; Node 24 LTS (`.nvmrc`). Ferramentas: ESLint, Prettier, Vitest, Testing Library, MSW, Playwright.

## Alternativas consideradas
- **npm / yarn:** pnpm é mais rápido e tem `node_modules` estrito (evita dependências fantasmas).
- **Jest:** Vitest é mais rápido e nativo em ESM/TS.

## Consequências
- Instalação local exige `corepack enable`.
- O Docker usa `pnpm install --frozen-lockfile`.
